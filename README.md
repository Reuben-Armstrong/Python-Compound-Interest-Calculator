# 💰 Compound Interest Calculator

A beginner-friendly **Python program** that calculates **compound interest** based on user input.  
Perfect for students learning Python, finance basics, or preparing for **GCSE Computer Science**.

---

## 📌 Features

- Calculate **final amount** and **total interest earned**
- User inputs: **Principal**, **Interest Rate**, **Time (Years)**
- **Input validation** to prevent errors
- Results rounded to 2 decimal places
- Clear, easy-to-follow interface

---

## 🧮 Formula Used

- **Compound Interest Formula**  
  A = P × (1 + r/100)^t

  Where:  
  - A = Final amount  
  - P = Principal (starting amount)  
  - r = Interest rate (percent per year)  
  - t = Time (in years)

---

## ▶️ How to Run

1. Make sure Python is installed (version **3.6 or higher** recommended).
2. Clone the repository or download the `.py` file.
3. Open a terminal or IDE and run the script:

   python compound_interest_calculator.py
